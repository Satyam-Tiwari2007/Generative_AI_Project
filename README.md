#  Project Overview


**AI Movie Studio: Life in 2050** is an academic Generative AI project that demonstrates how multiple AI technologies can be integrated to create a complete digital production pipeline.

The project explores the theme:

> **"Life in 2050: How AI Changes Human Life"**

The objective is to develop a **60–90 second AI-generated short film** along with an **interactive website** by combining various Generative AI tools for story writing, prompt engineering, image generation, video generation, voice synthesis, music generation, and AI-assisted programming.


---

# Objectives

- Compare different Generative AI tools
- Learn Prompt Engineering
- Generate AI Images
- Generate AI Videos
- Generate AI Voice & Narration
- Generate AI Music & Sound Effects
- Develop a website using AI Coding Assistant
- Evaluate AI-generated outputs
- Demonstrate Human-AI Collaboration
